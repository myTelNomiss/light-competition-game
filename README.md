## Overview

This repository implements an evolutionary game of shade-avoidance investment in dense plant stands. A plant's fitness is written as

> *W(s*_i, *s̄*, *N*) = k₀(1 + γs*_i*) + k₁(*s*_i − *s̄*)*N*^β − c·s*_i^α,

where *s*_i is the focal plant's shade-avoidance investment, *s̄* the population mean, and *N* the effective number of neighbours. The frequency-dependent term is zero-sum within a closed, light-saturated canopy and the cost term is convex (α > 1). Solving the first-order condition gives the evolutionarily stable strategy (ESS) and the population yield optimum in closed form:

> *s*\* = [ (k₀γ + k₁*N*^β) / (cα) ]^(1/(α−1)), &nbsp; *s*opt = [ k₀γ / (cα) ]^(1/(α−1)).

Because *s*opt contains no density term whereas *s*\* increases with *N*, the tragedy gap *s*\* − *s*opt and the associated yield loss rise with density. The code (i) derives both equilibria analytically and verifies the ESS with individual-based evolutionary simulations and pairwise invasion analysis; (ii) maps molecular light-signalling gain onto phenotype and breeding interventions; (iii) anchors the predicted magnitude with an independent tomato field trial using a scale-free identity; and (iv) examines robustness across a global parameter sample. Under the default parameters *s*opt = 0.333, the ESS rises from 0.533 at *N* = 100 to 0.899 at *N* = 800 (≈9.3% yield loss), reaching the strategy boundary at the highest densities. The field contrast (a 13.5% significant high-density yield advantage of a shade-hyposensitive tomato line) places a data-driven lower bound of *L* ≈ 11.9% on the wild-type loss, with a conditional 13–16% interval if the line retains *g* = 0.35–0.55 of the response.

## Reproducibility

Dependencies: Python 3.9+ with NumPy, pandas, Matplotlib, and SciPy (see `requirements.txt`).

```bash
pip install -r requirements.txt
cd src
python main.py
```

Running `main.py` executes the analytic model, the individual-based simulation, the pairwise-invasion analysis, the molecular mapping, the literature benchmark, the field inversion, and the global sensitivity analysis, and then regenerates all 19 CSV files in `data/` and all figures in `figures/`. The Monte Carlo analysis uses 6,000 parameter combinations with a fixed random seed (42), of which 3,974 interior solutions are retained; all reported numbers are reproducible from the committed code and data. The four structural predictions hold in every interior sample under the assumed sign structure (zero-sum competitive term, γ > 0).

Individual modules can also be run from `src/` (e.g. `python model.py`, `python sensitivity.py`).

### Source modules

| Module | Purpose |
|---|---|
| `config.py` | Default parameters, Monte Carlo sampling ranges, and random seed |
| `model.py` | Fitness function; closed-form ESS and population optimum; tragedy gap and yield loss |
| `simulation.py` | Individual-based evolutionary simulation, pairwise invasion analysis, and replicator dynamics |
| `benchmark.py` | Replication of four published qualitative patterns (Gersani 2001; Bongers 2019; Burbano-Erazo 2025; ESS ≠ population optimum) |
| `molecular.py` | Molecular gain *g* (sensing × downstream), genotype-to-phenotype mapping, and intervention ranking |
| `empirical_validation.py` | Digitization of the tomato field trial and scale-free inversion of *g* and loss *L* |
| `sensitivity.py` | One-at-a-time and global Monte Carlo sensitivity and robustness |
| `visualization.py` | Figure generation |
| `main.py` | Entry point that runs the complete workflow |

## Data provenance

Files in `data/` prefixed with `core_`, `evolution_`, `molecular_`, `breeding_`, `light_signaling_`, `benchmark_`, and `sensitivity_` are generated by the code. The five `burbano*` files contain treatment-level medians and the resulting ratios digitized from the open-access tomato field study of Burbano-Erazo et al. (2025, *New Phytologist*, https://doi.org/10.1111/nph.70384); statistical significance is taken from the original study rather than from the digitized values. See the manuscript for digitization uncertainty and the exclusion of one anomalous replicate.
